# Übersetzen

Die Oberfläche kennt sechs Sprachen: Deutsch (Ausgangssprache), Englisch, Französisch, Chinesisch, Japanisch, Russisch.

## Aufbau

`src/i18n/tr.json` ist ein Objekt. Der Schlüssel ist der **deutsche Satz** genau so, wie er im Code steht. Der Wert ist eine Liste mit fünf Texten in dieser Reihenfolge: `[en, fr, zh, ja, ru]`.

```json
"Protokoll löschen": ["Clear log", "Effacer le journal", "清除记录", "記録を消す", "Очистить журнал"]
```

Platzhalter in geschweiften Klammern (`{n}`, `{a}`, `{b}`) bleiben unverändert und werden im Code gefüllt.

## Neuen Text hinzufügen

1. Im Code `_('Dein deutscher Satz')` verwenden, mit Platzhaltern `_('{n} Beiträge',{n:3})`.
2. Denselben Satz mit fünf Übersetzungen in `tr.json` eintragen.
3. `python3 tools/build.py` ausführen. Das Skript bricht ab, wenn ein Eintrag keine fünf Texte hat.
4. `python3 tests/test_i18n.py` prüft für jede Sprache, ob deutsche Reste auf Bildschirmen übrig bleiben.

## Verbessern

Die vorhandenen Übersetzungen sind maschinell erstellt und freuen sich über Muttersprachler. Ändere den Wert in `tr.json` und öffne einen Pull Request.

## Neue Sprache

Die Sprachen sind an mehreren Stellen fest verdrahtet (Liste `LANGS_OK`, Sprachnamen im Ich-Tab, Einführungstexte, Reihenfolge der Listenwerte). Öffne zuerst ein Issue, damit wir die Stellen gemeinsam durchgehen.

## Einfache Sprache

Kurze Sätze, keine Fachwörter, eine Idee pro Satz. Das gilt in jeder Sprache.
